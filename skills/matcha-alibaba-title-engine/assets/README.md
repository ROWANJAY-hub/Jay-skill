# Optional title state

This portable package intentionally excludes private ledgers, historical source workbooks, and personal learning memory.

Agents may add current user-provided data here at runtime:

- `current-ledger.xlsx`
- `recent-session-titles.json`
- `learning-memory.json`
- `source-registry.json`
- `baseline-sources/`

When these files are absent, continue with confirmed product facts and current research; do not invent historical metrics or claim that private baseline data was consulted.
