# Platform & Research Profiles V1.1

版本：V1.1
日期：2026-09-05
定位：芝麻开门工作流的平台与跨平台调研策略。

## 1. Final Target
- 唯一最终平台：Alibaba International / 阿里国际站。
- `芝麻开门` 不再询问平台。
- 最终标题、关键词、图片方向、交付规范必须回到 Alibaba。

## 2. Alibaba
- Title Skill：ACTIVE_SKILLS 指定 Alibaba Title Skill。
- 标题 ≤128字符。
- 关键词池默认 ≤384字符。
- 避免 US/USA Stock/US Warehouse/Warehouse/In Stock。
- 默认不以 Wholesale/Bulk/Factory Direct/Supplier/Manufacturer 作为标题头词。
- 实际能力允许时优先 Custom/Customized/Personalized/Custom Logo/Custom Packaging/OEM/Private Label。
- 图片默认1:1；图片槽位由活动 Image Skill 定义。

## 3. Cross-Platform Research Sources
这些平台是研究源，不是最终输出平台。

### Amazon
适合研究：
- 买家关心的卖点
- 主图与场景结构
- 细节展示
- 产品使用逻辑
- Review/Listing 中高频购买关注点

### Temu
适合研究：
- 高点击视觉
- SKU/数量感
- C端使用场景
- 强主体构图

### Etsy
适合研究：
- 礼赠
- 个性化
- 手作/定制语言
- 节日与人群场景

### Independent Brand Sites
适合研究：
- 高端场景
- 包装表现
- 品牌视觉语言
- 情绪化构图

### Wayfair
仅家居/家具/收纳相关产品时研究：
- 家居真实空间
- 尺寸/空间关系
- 使用场景

## 4. Research-to-Output Rule
跨平台研究只能回答：
- “怎么表达更好”
- “怎么展示更好”
- “买家在意什么”
不能回答：
- “当前产品一定有什么规格/功能”
- “当前产品的尺寸/认证/材质是什么”

最终必须经过 Alibaba Profile + Product Truth 过滤。

## 5. Sparse Input
用户只给一张图时：
- 不追问平台
- 不因缺尺寸/后台数据中断
- 用 Alibaba + 相关跨平台研究做 Best-Effort
- 未确认硬事实省略
- 完整交付后再给可选增强提醒
