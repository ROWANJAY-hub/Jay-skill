# Zero Interrupt Adapter V1.0｜芝麻开门专用兼容层

版本：V1.0
日期：2026-09-07
作用：解决“芝麻开门零打断”与 Jay 图片 V4.0 / Title Skill 中“低置信度先提问”的冲突。

## 1. 适用范围
仅当 Master Trigger = `芝麻开门` 时生效。
不修改 Jay V4.0 的槽位、身份红线、QA、方法能力门；只覆盖“是否因普通缺资料而中断”的行为。

## 2. 优先级
用户当前明确要求 > 当前原始产品资料 > 本 Adapter > 活动 Router > Jay V4.0 / Title Skill 中的提问型阻断条款。

## 3. 缺失信息的安全降级
- 未确认套装件数：N=null；建立 Provisional Visible BOM，只展示当前图明确可见的独立销售件，不在标题写件数，不复制/补齐不可见件。
- 包装归属不清：默认归 K，不计入销售件数；Delivery Audit 提醒。
- 尺寸缺失：不猜尺寸；P6 改第二场景。
- 容量缺失：标题不写容量。
- 材质不确定：可用通用品类词；硬材质词仅在当前图高置信度且不涉及认证/性能时使用，否则省略。
- Logo/小字不清：不猜写；保留、弱化、避开展示或确定性处理。
- 单角度：不生成未知背面；P4 用安全机位/排列变化。
- 后台数据缺失：用活动台账 + 实时 Alibaba + 合理跨平台研究完成；交付后提醒可补数据优化。

## 4. Provisional P0
P0 允许状态：CONFIRMED 或 PROVISIONAL_SAFE。
PROVISIONAL_SAFE 可进入 P1-P6，条件是：
1. 不创造不可见产品/规格；
2. 不对不确定硬事实做文字声明；
3. P1/P4 只展示当前资料明确可见的产品资产；
4. 所有缺失项进入 Delivery Audit，而不是中途提问。

## 5. 仍可硬阻断
只允许：工具额度/系统限制、安全限制、方法能力完全不可用且无安全降级方案。
