# Jay Skills

Portable skill packages for Alibaba title generation and reference-faithful ecommerce product image generation.

Included:

- `matcha-alibaba-title-engine`
- `generate-faithful-product-images`
- `jay-autopilot-router`

This export contains the executable skill instructions, router, control-plane references, validation scripts, agent metadata, and icons. Private ledgers, learning memory, source workbooks, and baseline datasets are intentionally excluded. A new agent can load `skills/jay-autopilot-router/SKILL.md` as the entry point and then delegate to the two specialist skills.
